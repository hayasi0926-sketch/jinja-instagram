| ファイル名 | 使用スライド | 内容 |

## 再取得する場合

アプリの見た目が変わった場合や、別の神社に差し替えたい場合は、
プロジェクトルートで以下を実行すると自動的に再取得できます。

```bash
node scripts/fetch-app-screenshots.js
```

取得元のURLや対象神社（北海道神宮のID）は
`scripts/fetch-app-screenshots.js` の先頭で変更できます。
