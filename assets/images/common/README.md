# 共通画像フォルダ

全投稿で共通して使う画像（アプリのロゴ画像など）を置く場合に使用します。

現在、フッターのロゴマーク（鳥居アイコン）は画像ではなく SVG コードとして
各スライド HTML 内に直接書かれています（`<svg class="mark">...`）。

正式なアプリロゴ画像に差し替えたい場合は、
1. ここにロゴ画像（例：`app-logo.png`、背景透過推奨）を置く
2. 各スライド HTML の `<svg class="mark">...</svg>` の部分を
   `<img class="mark" src="../../assets/images/common/app-logo.png">` に書き換える

という手順になります。
