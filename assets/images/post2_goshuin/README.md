# 投稿②で使用する画像（実際のアプリ画面）

このフォルダの画像は、すべて実際の公開アプリ
（https://shrine-map-zeta.vercel.app）から取得したスクリーンショットです。
架空の電子御朱印デザインは一切含まれていません
（電子御朱印そのもののデザイン画面はログインが必要なため、現時点では取得できていません）。

| ファイル名 | 使用スライド | 内容 |
|---|---|---|
| `slide2-goshuin-box.jpg` | 2枚目 | 神社詳細ページ内にある「電子御朱印」案内ボックス |
| `slide3-login-modal.jpg` | 3枚目 | 「参拝する」ボタン→ログイン（ボトムシート）の実際の導線 |

## 再取得する場合

```bash
node scripts/fetch-app-screenshots.js
```

## 電子御朱印のデザイン画面そのものを使いたい場合

実際にログインして参拝記録を1件作成し、発行された電子御朱印の画面を
スクリーンショットしてこのフォルダに追加してください。
その場合は投稿②の構成（「開発中」の切り口）も合わせて見直しが必要です。
